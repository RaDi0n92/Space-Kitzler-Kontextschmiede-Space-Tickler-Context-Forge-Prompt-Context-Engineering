# Die unbequemen Loop-Fragen

    Woher kommt beim nächsten Umlauf **neue** Information? Wenn keine, warum überhaupt wiederholen?

    Woran ist ein Fehler von einem bloß anderen Stil zu unterscheiden? Ein Observer darf Kreativität nicht auf seine Lieblingsausgabe begrenzen.

    Welche Kosten, Rechte, Datenzugriffe und Stoppbedingungen existieren wirklich? Eine künftige Automation darf keinen verborgenen Dauerauftrag vortäuschen.

    Wie werden Quellen, historische Versionen und verworfene Ideen über Iterationen erhalten, ohne falsche Erinnerungen zu verhärten?

    Wie kann ein Mensch die Schleife unabhängig von inneren Modellprozessen verstehen und beeinflussen?

    Wann verhindert eine Korrekturschleife Neues, weil sie jeden ungewöhnlichen Vorschlag sofort auf den Altzustand zurückbiegt?

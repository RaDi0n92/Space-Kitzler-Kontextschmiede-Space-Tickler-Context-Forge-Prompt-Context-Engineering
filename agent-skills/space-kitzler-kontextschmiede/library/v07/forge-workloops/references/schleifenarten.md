# Offene Schleifentypen

    **Quellenschleife:** neuer Lesefund → alte Interpretation neu prüfen → eventuell neue Quelle suchen.

    **Denkbrückenschleife:** Hypothese aus A und B → kritischer Widerspruch aus C → alternative neue Verbindung.

    **Forschungsschleife:** Behauptung → Originalpaper/Code → Gegenbefund → konditionale Anwendung statt blindes Übernehmen.

    **Arbeitsqualitätsschleife:** fertiger Entwurf → reale Probe → Fehler → gezielte Reparatur → neue Probe.

    **Zeit-/Ereignisautomation:** ausgelöst durch Zeit, Zustand oder freigegebenes Ereignis. Nicht gleichbedeutend mit einem Denkloop.

    **Graph-Rückkopplung:** ein künftiger Controller könnte Knoten-/Kanteninformationen nutzen. Diese Möglichkeit wurde ausdrücklich **vertagt**, sie ist weder eingebaut noch beauftragt.

    Erhalte das offene „vielleicht“, statt es als technische Zusage in den Kernsatz zu schreiben.

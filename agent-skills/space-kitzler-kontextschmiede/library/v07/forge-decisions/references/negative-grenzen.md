# Vier sehr unterschiedliche Arten von „nicht“

    1. **Harte aktuelle Untersagung:** Der Nutzer schließt eine Aktion aus. Nicht aus Versehen als Experiment reinholen.
    2. **Gescheiterter Weg:** Das alte Scheitern gilt als historische Information. Der Weg kann unter neuen Umständen erneut interessant werden, aber nicht heimlich als Erfolgsrezept ausgegeben werden.
    3. **Vertagung:** Eine Integrationsidee ist ausdrücklich separat dokumentiert; der Compiler darf sie nicht in den Kern zurückschreiben.
    4. **Stilistische Präferenz:** „Nicht glattbügeln“ heißt Originaltone, Friktion, Unerwartetes bewahren; nicht zwanghaft holprig schreiben.

    Nutze ein konkretes Beispiel aus Originalmaterial statt generische Warnungen. Jede künstliche neue Einschränkung ist selbst eine potenzielle Verfälschung.

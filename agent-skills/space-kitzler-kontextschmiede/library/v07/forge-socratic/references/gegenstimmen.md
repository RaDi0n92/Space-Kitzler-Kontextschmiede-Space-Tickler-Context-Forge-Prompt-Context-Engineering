# Gegenstimmen ohne Theater

    Die „erste Gegenstimme“ soll eine **inhaltlich begründete** andere Lesart sein, nicht „Es könnte Risiken geben“. Suche vorhandene Gegenevidenz oder eine alternative Interpretation derselben Quelle.

    Besonders gefährlich: die gegnerische Position so schwach zu zeichnen, dass die eigene Lieblingsidee immer gewinnt. Eine gute Gegenprobe darf gewinnen.

    Verwechsle Sokrates nicht mit versteckter Chain-of-Thought-Ausgabe. Gefragt sind öffentlich überprüfbare Argumente, Kontraste, neue Fragen und Schlussfolgerungen. Ein selbsternannter innerer Gedankenknoten ist kein Messwert.

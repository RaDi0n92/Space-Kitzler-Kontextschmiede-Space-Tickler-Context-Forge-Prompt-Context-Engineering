# Angriff auf hübsche, aber leere Verbindungen

    Ersetze in der Aussage die beiden Dokumenttitel durch beliebige andere: bleibt der Satz trotzdem plausibel? Dann war er wahrscheinlich generisch.

    Besteht die „neue“ Idee nur aus der Summe zweier Schlagworte? Welche echte Überraschung oder neue Prüfung wurde dadurch möglich?

    Wird aus Metapher („graphartige Idee“) die technische Behauptung („es gibt einen funktionierenden Graphserver“)? Nicht zulässig.

    Wird eine verworfene Nutzeridee durch kreative Umformulierung heimlich wieder eingeführt? Erlaubte Kreativität respektiert die Geltung von Entscheidungen.

    Ist der Folgeagent auf eine Erzählung festgelegt? Füge die interessante Gegenlesart hinzu, notfalls als offene Frage, nicht als Pflichtplan.

    Eine Brücke darf scheitern; das Scheitern einer vermeintlichen Verbindung ist selbst ein nützlicher Befund.

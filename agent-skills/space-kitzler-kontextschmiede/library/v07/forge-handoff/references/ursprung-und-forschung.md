# Projektkontext und Forschungsstartpunkte (nicht unbesehen als Fakten übernehmen)

Diese Referenz hält die im Gespräch vom 17.10.2026 genannten Ansätze fest. Das eigentliche ausführliche Projektverständnis ist auf dem VPS im vom Nutzer angelegten Projektverzeichnis dokumentiert. Eine bloße Erwähnung eines VPS-Pfads heißt nicht, dass das Dokument gerade gelesen wurde.

**Projektgeschichte:** Prompt Engineering Expert → Plugin Autopilot (Fehlinterpretation: Plugin-Generator) → Prompt Engine Ultra → Context Forge Ultra. Nutzerkorrekturen: Quellen zuerst tatsächlich lesen; die zu übergebenden Originale auch dem Folgeagenten ausdrücklich zur eigenen Lektüre empfehlen; keine starre Denkart vorschreiben; viele unterschiedliche Perspektiven als Angebote; autonome Automationen/Loops nur als Möglichkeiten, nicht ungefragt einrichten; Harness-Kopplung separat und vorläufig.

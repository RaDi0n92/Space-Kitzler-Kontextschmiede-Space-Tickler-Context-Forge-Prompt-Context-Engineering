# Space-Kitzler-Kontextschmiede Agent Skills

## English

This folder contains the 18 full skills in a portable, folder-based `SKILL.md` layout. Each skill can be read or copied separately. The complete folder preserves the sibling skills and reference library used by cross-skill links.

### Use with a skills-compatible agent

Place the skill folders in the agent's configured skills directory, or upload the complete `Space-Kitzler-Kontextschmiede-Agent-Skills-0.10.0.zip` if that agent accepts this package layout. Keep the full folder tree when possible; copying only one `SKILL.md` may omit referenced specialist skills or research files. The distribution ZIP includes the repository's MIT license; keep that notice when copying or redistributing licensed content.

### Use with another agent

Open the requested `SKILL.md` and provide its full text as instructions or context. When it refers to another skill or a file under `space-kitzler-kontextschmiede/library/`, provide that dependency too. The `@skill` names are the original ChatGPT plugin invocation convention; translate them into the target agent's skill-selection method.

The skill files are in German, matching the original plugin. This folder changes only the main skill folder name and relative paths needed to make the Agent Skills export self-contained; it does not translate or redesign the skill content. Tools, permissions, host features, and automatic activation still depend on the target agent. This package cannot make every agent automatically compatible.

## Deutsch

Dieser Ordner enthält alle 18 vollständigen Skills in einer portablen, ordnerbasierten `SKILL.md`-Struktur. Jeder Skill kann einzeln gelesen oder kopiert werden. Die vollständige Ordnerstruktur erhält die Fachskills und Referenzbibliothek, auf die Querverweise zugreifen.

### Mit einem Agenten verwenden, der Skills unterstützt

Lege die Skill-Ordner in den konfigurierten Skill-Ordner des Agenten oder lade das vollständige `Space-Kitzler-Kontextschmiede-Agent-Skills-0.10.0.zip` hoch, sofern der Agent dieses Paketformat annimmt. Bewahre möglichst den ganzen Ordnerbaum; beim Kopieren nur einer `SKILL.md` können referenzierte Fachskills oder Forschungsdateien fehlen. Das Weitergabepaket enthält die MIT-Lizenz des Repositorys; erhalte diesen Hinweis beim Kopieren oder Weitergeben lizenzierter Inhalte.

### Mit einem anderen Agenten verwenden

Öffne die gewünschte `SKILL.md` und gib ihren vollständigen Text als Anweisung oder Kontext weiter. Verweist sie auf einen anderen Skill oder eine Datei unter `space-kitzler-kontextschmiede/library/`, gib auch diese Abhängigkeit mit. Die `@skill`-Namen entsprechen der Aufrufkonvention des ursprünglichen ChatGPT-Plugins; übertrage sie in die Skill-Auswahl des Zielagenten.

Die Skill-Dateien sind wie das Original-Plugin auf Deutsch. Dieser Ordner ändert nur den Namen des Hauptskill-Ordners und die relativen Pfade, die der eigenständige Agent-Skills-Export braucht; die Skill-Inhalte werden weder übersetzt noch neu gestaltet. Werkzeuge, Berechtigungen, Hostfunktionen und automatische Aktivierung hängen weiterhin vom jeweiligen Agenten ab. Dieses Paket kann keine automatische Kompatibilität mit jedem Agenten herstellen.

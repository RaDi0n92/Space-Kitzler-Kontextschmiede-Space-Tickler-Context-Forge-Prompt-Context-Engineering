# Active skills catalog

## English

The live package contains 18 active skill files. The 17 specialists are separately addressable but remain optional. Their names and paths below match the live package inventory.

Open [`skills/README.md`](../skills/README.md) for direct links to the complete, copyable text of every skill in both the Agent Skills export and the original plugin package.

| Active skill | Focus |
|---|---|
| space-kitzler-kontextschmiede | Main entry for accessible context, source-grounded interpretation, handoffs, prompts, analysis, and explicitly requested work. |
| arbeitsauftrag | Turn project context into a ready-to-use work order or master prompt. |
| arbeitskreislauf | Carry work through a practical loop of action, result read-back, checking, and correction. |
| autorisierte-umsetzung | Execute explicitly authorized work with available tools and verify the result. |
| denkbruecken | Build material-grounded links between distinct sources, levels, or time periods. |
| denkwerkstatt | Develop deeper and competing approaches for complex work without making a research checklist. |
| entscheidungsstatus | Distinguish current decisions, superseded ideas, conflicts, prohibitions, and deferred options. |
| forschung | Study papers, repositories, issues, and technical sources and turn useful findings into concrete behavior. |
| gegenfragen | Develop questions and counterpositions that can genuinely move the interpretation. |
| kontextuebergabe | Produce an independent context handoff with evidence, decisions, open questions, and source access. |
| perspektiven | Generate distinct and competing interpretations grounded in the available material. |
| pluginbau | Translate workflows into a real plugin only when plugin building is explicitly requested. |
| projektgeschichte | Reconstruct a project timeline, its corrections, and why the current decision exists. |
| quellenlesen | Read originals and distinguish actual reading from paths, search results, and summaries. |
| repo-erkenntnisse | Transfer practical learning from repositories without treating them as endorsements or installing them automatically. |
| uebergaben-pruefen | Check a handoff against originals for source, status, and claim errors. |
| wiedereinstieg | Help a new session or agent resume work critically from a handoff. |
| wirkungsvergleich | Compare a handoff or skill with a fair baseline using actual independent task runs. |

The plugin advises choosing only the specialists relevant to the user's request. The specialist catalog is not a mandatory sequence. The main skill remains the general route.

## Deutsch

Das Livepaket enthält 18 aktive Skill-Dateien. Die 17 Fachskills können einzeln aufgerufen werden, bleiben aber optional. Die folgenden Namen und Pfade stimmen mit der Live-Dateiliste überein.

Unter [`skills/README.md`](../skills/README.md) findest du direkte Links zu den vollständigen, kopierbaren Texten aller Skills im Agent-Skills-Export und im Original-Pluginpaket.

| Aktiver Skill | Schwerpunkt |
|---|---|
| space-kitzler-kontextschmiede | Haupteinstieg für zugänglichen Kontext, quellenbasierte Deutung, Übergaben, Prompts, Analyse und ausdrücklich beauftragte Arbeit. |
| arbeitsauftrag | Projektkontext in einen direkt nutzbaren Arbeitsauftrag oder Masterprompt überführen. |
| arbeitskreislauf | Arbeit mit Handlung, Ergebnisrücklesung, Prüfung und Korrektur praktisch fortführen. |
| autorisierte-umsetzung | Ausdrücklich beauftragte Arbeit mit verfügbaren Werkzeugen ausführen und das Ergebnis prüfen. |
| denkbruecken | Materialgestützte Verbindungen zwischen unterscheidbaren Quellen, Ebenen oder Zeitständen herstellen. |
| denkwerkstatt | Für komplexe Arbeit tiefere, konkurrierende Ansätze entwickeln, ohne eine Forschungscheckliste vorzuschreiben. |
| entscheidungsstatus | Aktuelle Entscheidungen, ersetzte Ideen, Konflikte, Verbote und vertagte Optionen unterscheiden. |
| forschung | Studien, Repositories, Issues und technische Quellen untersuchen und brauchbare Funde in konkretes Verhalten übersetzen. |
| gegenfragen | Fragen und Gegenpositionen entwickeln, die eine Deutung tatsächlich bewegen können. |
| kontextuebergabe | Eine eigenständige Kontextübergabe mit Belegen, Entscheidungen, offenen Fragen und Quellenzugang erstellen. |
| perspektiven | Unterschiedliche und konkurrierende, im Material verankerte Deutungen entwickeln. |
| pluginbau | Abläufe nur dann in ein echtes Plugin übersetzen, wenn Pluginbau ausdrücklich beauftragt ist. |
| projektgeschichte | Projektverlauf, Korrekturen und Gründe aktueller Entscheidungen rekonstruieren. |
| quellenlesen | Originale lesen und tatsächliche Lektüre von Pfaden, Suchtreffern und Zusammenfassungen unterscheiden. |
| repo-erkenntnisse | Praktische Erkenntnisse aus Repositories übertragen, ohne sie als Gütesiegel zu behandeln oder automatisch zu installieren. |
| uebergaben-pruefen | Eine Übergabe anhand der Originale auf Fehler bei Quelle, Status und Aussagen prüfen. |
| wiedereinstieg | Einer neuen Sitzung oder einem Agenten helfen, eine Arbeit kritisch anhand der Übergabe fortzuführen. |
| wirkungsvergleich | Übergaben oder Skills anhand echter unabhängiger Aufgabenläufe mit einer fairen Baseline vergleichen. |

Das Plugin empfiehlt, nur die Fachskills zu wählen, die zur konkreten Nutzeranfrage passen. Der Katalog ist keine Pflichtabfolge. Der Hauptskill bleibt der allgemeine Einstieg.

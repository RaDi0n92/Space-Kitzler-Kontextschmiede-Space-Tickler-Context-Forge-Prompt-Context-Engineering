# Materialkarte und reversible Herkunft

    Ein Eintrag darf ausführliche Prosa enthalten; strukturierte Felder sind nur eine zweite Sicht. Ordne die Beobachtung einer belegten Passage zu, notiere das Zeitfenster des Dokuments und trenne Nutzeraussage von Dokumentautor und eigener Schlussfolgerung. Bei Wiedergabe fremder Inhalte Quellenstatus und Rechte beachten.

    **Zugriffsgrade:** original vollständig gelesen / Original teilweise gelesen / angezeigter Treffer / sekundär berichtet / nur erwähnt / verweigerter Zugriff / technisch unbewertbar. „Voll“ setzt tatsächlich beobachteten Umfang voraus. Für einen Vorgänger von gestern ist ein vorliegendes summarisches Dossier weiterhin **sekundär**, auch wenn es überzeugend klingt.

    **Ungewöhnliche Lesefrage:** Was an dieser Quelle würde ich anders verstehen, wenn eine weitere Datei gerade das Gegenteil zeigt? Welche Nebensätze wirken irrelevant, könnten aber nach einer technischen Korrektur plötzlich zentral sein? Welche Lieblingsdeutung stammt von mir statt vom Material?

    **Reversible Verdichtung:** Die Leseprobe soll die Originalfundstelle offenhalten. Nicht nur „Fehler, der später behoben wurde“, sondern wann, wodurch, ob der Fehler wirklich behoben wurde, und welches Wissen zur Wiederaufnahme benötigt wird.

# Knoten, Kanten und produktive Denkbrücken

**Nur laden**, wenn mindestens zwei relevante Quellen, zeitliche Versionen oder konkurrierende Deutungen vorliegen oder der Nutzer ausdrücklich ungewöhnliche Querverbindungen möchte. Keine graphbasierte Pflichtmaschine bauen.

Eine mögliche Denkbrücke (narrativ oder intern strukturiert):

- **Knoten A:** Materialstelle (ID, Locator, konkreter Befund), noch keine große These.
- **Knoten B:** andersartiger Befund, Entscheidung, Misserfolg, ungewohnte Perspektive.
- **Kante:** präzise Art der Beziehung, z. B. *erklärt*, *widerspricht*, *setzt voraus*, *folgt zeitlich*, *begrenzt*, *ist nur Analogie*, *macht Frage interessant*.
- **Gegenkante:** Weshalb könnte der Zusammenhang falsch, übertrieben oder zu einem anderen Scope gehörig sein?
- **Mögliche Synthese:** Welche neue, noch nicht entschiedene Frage bzw. Sicht entsteht und was könnte sie verifizieren?

Brücken können mehrere Ebenen verbinden: eine frühe Absicht ↔ späteres Fehlverhalten ↔ technische Restriktion ↔ menschliche Erfahrung ↔ externe Forschung. Eine überraschende Verbindung darf gern lebendig formuliert werden, **aber** Kausalität nur bei belastbarem Nachweis, Analogien ausdrücklich als solche.

Wenn es nur eine Quelle gibt, kann die Spannung innerhalb dieser Quelle oder zwischen ihrer ersten und ihrer späteren Version entstehen. Bei unzureichender Datenbasis kreativ offene Fragen statt erfundener Verbindungen anbieten.

**Anti-Schablone:** Keine künstlichen 18 unabhängigen Boxen; keine vorgegebenen Denkspuren; Perspektiven sind **Einladungen**, keine Handlungsaufforderungen an verstecktes Chain-of-Thought. Das Ergebnis kann als fließende Erzählung, freies Netz oder lose Impulsfolge erscheinen. Erhalt bestehender Nutzerentscheidungen bleibt unabhängig davon überprüfbar.

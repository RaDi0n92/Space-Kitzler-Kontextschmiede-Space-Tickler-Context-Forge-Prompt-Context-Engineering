# Drei anspruchsvolle Masterprompt-Fälle und ihre Fallstricke

## 1. Alte Entscheidung kontra gegenwärtigem Auftrag

Historischer Kontext: Der Nutzer wollte ein anspruchsvolles Plugin für Kontext-zu-Prompt-Übergaben. Eine Zwischenstation hielt ein Plugin, das selbst Plugins baut, für das eigentliche Ziel. Später wurde gerade das ausdrücklich korrigiert.

Eine mangelhafte Kompilation schleppt beide Ansätze mit identischer Geltung in den neuen Prompt. Eine bessere Kompilation macht die Entwicklung verständlich und richtet die nächste *konkrete* Bearbeitung am heutigen Ziel aus. Der neue Agent darf die historische Fehlannahme als Warnung und als kreative Frage ansehen, nicht als wieder gültigen Bauauftrag.

## 2. Hohe kreative Freiheit kontra tatsächlichem Eingriff

Wenn das Problem laut Nutzer „das vorhandene System funktioniert nicht“ lautet, darf der Handoff offen machen, *welche* alternativen Erklärungen und neuen Wege sinnvoll erscheinen. Er muss zugleich konkret sagen, welche Umgebung und welche Veränderung gewünscht und erlaubt sind. Die Offenheit ist in der *Lösungsbildung* wichtig; die Zielerreichung darf nicht durch eine Methodenrede ersetzt werden.

Bei einem reinen Denkauftrag darf dagegen ein unaufgeforderter Eingriff ein Fehler sein. Die Ausgangsberechtigung unterscheidet beide Situationen. Eine gute Folge-KI muss dies im Text erkennen können.

## 3. „1000 % besser“ kontra unbewiesene Leistungssteigerung

Die hohe Qualitätserwartung ist real. Sie sagt nicht, dass ein Test schon gewonnen wäre. Erstelle einen sehr guten Prompt, aber prüfe eine konkrete Aufgabe mit einer einfachen sorgfältigen Alternative. In der Auswertung stehen reale Beobachtungen, Fehler und nicht bewertbare Fälle, keine aus dem Gefühl entstandene Prozentangabe. Wird der Vergleich nicht tatsächlich ausgeführt, darf er nicht als erfolgt ausgegeben werden.

## Vergleichsfrage

Was konnte der Zielagent mit dem neuen Prompt konkret besser *tun*, nicht nur schöner beschreiben? Was hat er übersehen, dessen Fehlen erst eine erneute Originallektüre sichtbar gemacht hätte? Wo hat der Vorgänger ihm eine Entscheidung abgenommen, die erst sein eigenes Materialverständnis hätte erlauben sollen?

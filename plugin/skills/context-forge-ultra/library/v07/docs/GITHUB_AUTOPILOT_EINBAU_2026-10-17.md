# Context Forge Ultra – GitHub-Erfahrungen und Plugin Autopilot eingebracht

**Stand 17.10.2026.** Diese Datei dokumentiert, *warum* die GitHub-Recherche und das installierte Plugin Autopilot in die Context-Forge-Fähigkeiten eingeflossen sind. Sie ist zugleich eine mögliche Quelle für das später gesondert zu entwickelnde Plugin **„Mit ChatGPT richtige Plugins bauen“**. Dieses Meta-Plugin wurde **nicht** erstellt.

## Gelesen und herangezogen

- Eigenes Context-Forge-Material: ausführliche Langfassung der ursprünglichen Idee, Forschungsverweise und die bereits installierten Skill-Inhalte der Version 0.4.0.
- Installierter `chatgpt-codex-plugin-autopilot`: Hauptskill, `agentic-repo-discovery`, `workflow-to-skill-compiler`, `plugin-experience-architect` und die vorhandenen offiziellen Plugin-Creator-Skills. Der gesamte externe Plugin-Autopilot-Quellcode wurde nicht in dieses Plugin kopiert.
- Öffentlich erneut untersuchte GitHub-Quellen: `Tiger3807861189/J-Space-Cognition-Suite`, `sina85/sina-gpt` (J-Space objective), `igorbarshteyn/jlens-gguf`, `facebookresearch/coconut`, `stanfordnlp/dspy` (MIPROv2/GEPA), `promptfoo/promptfoo`, `f/prompts.chat`. Weiterhin referenziert: `x1xhlol/system-prompts-and-models-of-ai-tools`.
- Dokumentationsgrundlage für die offizielle Plugin-Verpackung: installierte `plugin-creator/create-plugin`- und `update-plugin`-Skills samt Paket-/Update-Vertrag.

## Wie die Forschung praktisch werden soll

**Nutzerwunsch:** Keine stumpfe Aufzählung, kein wissenschaftliches „umstritten und Gegenargumente“-Ritual für einen neuen Agenten. Er soll verstehen, *welches Problem* eine Arbeit behandelt, *welche Grundidee* daraus entsteht und *wie er sie in seinem eigenen Auftrag verwenden könnte*.

Dafür enthält das Plugin neue Referenzen mit anschaulichen Projektbeispielen, vor allem `forge-repo-practices/references/github-lernpfade.md` und `forge-agent-reentry/references/forschung-als-einladung.md`. Die Umsetzung kann optional den praktischen Transfer von Repository-Ideen diskutieren, **ohne fremde Projekte automatisch zu installieren oder deren Code als eigenen auszugeben**.

Plugin Autopilot ist als **Herstellungs- und Verifikationshilfe** verwendet worden, nicht zur Umdeutung von Context Forge in einen Plugin-Generator. Die später mögliche Meta-Plugin-Idee bleibt eigenständig dokumentierbar unter `/root/werkraum/_gpt/Pluginbau_ChatGPT/`.

## Warum eigene Beispielstücke notwendig sind

Ein Skill, der schreibt „Sei kreativ, verbinde Perspektiven“, kann diesen Anspruch formal erfüllen und dennoch nur Floskeln erzeugen. Die neuen Beispiele zeigen aus unseren echten Gesprächskorrekturen die Bewegung von Quellenanker über Irrtum und Gegenlesart hin zu einer neuen möglichen Frage. Das ist vorbildhaft für den Agenten und zugleich offen genug, dass er eine abweichende Sicht entwickeln darf.

## Ungeprüft

Eine installierte Textanweisung beweist nicht, dass ChatGPT sie zur richtigen Zeit auswählt oder der Folgeagent mit ihr tatsächlich bessere Ergebnisse produziert. Ein echter Vergleich mit unabhängigen Zielagenten und identischem Quellenzugang bleibt ausstehend. Interne neuronale Modellzustände sind durch diese Einbindung weder auslesbar noch steuerbar.
